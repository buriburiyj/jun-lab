우분투 리눅스 재미있는 명령어 실험

주제: 인터넷에서 흥미로운 주제를 하나 찾아서 직접 실험해 봐
결과: 성공 · 행동 13번 · 모델 nvidia/nemotron-3.5-super-vl-120b-a12b

정리

우분투 26.04 LTS에서 재미있는 리눅스 명령어 네 가지를 설치하고 직접 실험했다. cowsay와 figlet은 스크립트 환경에서도 정상적으로 작동하여 ASCII 아트 소와 대형 배너 텍스트를 출력했다. sl(증기 기관차)과 cmatrix(매트릭스 효과)는 ncurses 기반 전체 화면 애니메이션으로, 비대화형 터미널에서는 원시 ANSI 이스케이프 코드만 출력되고 시각적 효과는 나타나지 않았다. 이는 대화형 터미널($TERM 설정과 실제 tty)이 필요하기 때문이다. 실험 결과와 요약 보고서는 ~/ws/out/experiment_results.txt와 ~/ws/out/summary.txt에 저장했다. 다음에는 대화형 터미널에서 sl과 cmatrix를 직접 실행해 시각 효과를 확인해 볼 수 있다.
