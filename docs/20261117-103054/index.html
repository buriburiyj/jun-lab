퍼블릭 DNS 서버 응답 시간 비교 실험

주제: 인터넷에서 흥미로운 주제를 하나 찾아서 직접 실험해 봐
결과: 성공 · 행동 8번 · 모델 nvidia/nemotron-3.5-super-vl-120b-a12b

정리

인터넷에서 흥미로운 주제로 퍼블릭 DNS 서버의 응답 속도를 직접 측정하는 실험을 진행했다. dig 명령으로 Google(8.8.8.8, 8.8.4.4), Cloudflare(1.1.1.1, 1.0.0.1), OpenDNS(208.67.222.222) 등 5개 퍼블릭 DNS 서버에 example.com을 각각 3회 질의해 응답 시간을 기록했다. 결과는 ~/ws/out/dns_results.csv에 저장했고, 평균 응답 시간과 오차 범위를 막대 그래프로 ~/ws/out/dns_comparison.png에 그렸다.

측정 결과, Cloudflare 1.0.0.1이 평균 10.0ms로 가장 빨랐고, 1.1.1.1이 평균 16.0ms, OpenDNS가 13.0ms였다. Google의 8.8.8.8(37.0ms)과 8.8.4.4(37.3ms)는 가장 느렸다. 지역 네트워크 환경에 따라 순위는 달라질 수 있지만, 이 환경에서는 Cloudflare 서버가 응답 속도에서 우위를 보였다. matplotlib가 처음 설치되지 않아 pip로 설치한 후 그래프를 생성하는 과정이 있었다.

다음에는 더 많은 도메인을 대상으로 측정하거나, DNS 캐싱 유무에 따른 응답 시간 차이를 비교해 볼 수 있다.

[4] shell 퍼블릭 DNS 서버별 dig 응답 시간 측정 및 CSV 저장
mkdir -p ~/ws/out
echo "server,query_time_ms" > ~/ws/out/dns_results.csv
for server in 8.8.8.8 1.1.1.1 208.67.222.222 1.0.0.1 8.8.4.4; do
  for i in 1 2 3; do
    qt=$(dig @$server example.com +stats 2>/dev/null | grep "Query time:" | awk '{print $4}')
    echo "$server,$qt" >> ~/ws/out/dns_results.csv
  done
done

[5] shell DNS 응답 시간 데이터 분석 및 그래프 생성
python3 - << 'EOF'
import csv
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
from collections import defaultdict

data = defaultdict(list)
with open('/root/ws/out/dns_results.csv') as f:
    reader = csv.DictReader(f)
    for row in reader:
        if row['query_time_ms']:
            data[row['server']].append(int(row['query_time_ms']))

servers = sorted(data.keys())
avgs = [sum(data[s])/len(data[s]) for s in servers]
mins = [min(data[s]) for s in servers]
maxs = [max(data[s]) for s in servers]

print("서버별 응답 시간 통계 (ms):")
for s in servers:
    print(f"  {s}: 평균={sum(data[s])/len(data[s]):.1f}, 최소={min(data[s])}, 최대={max(data[s])}, 측정={data[s]}")

plt.figure(figsize=(8,5))
x = range(len(servers))
plt.bar(x, avgs, yerr=[[a-m for a,m in zip(avgs,mins)],[M-a for a,M in zip(avgs,maxs)]], capsize=5, color='steelblue', edgecolor='black')
plt.xticks(x, servers)
plt.ylabel('Query time (ms)')
plt.title('Public DNS Server Response Time Comparison (example.com)')
plt.grid(axis='y', alpha=0.3)
plt.tight_layout()
plt.savefig('/root/ws/out/dns_comparison.png', dpi=150)
print("그래프 저장: /root/ws/out/dns_comparison.png")
