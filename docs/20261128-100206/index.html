리눅스에서 소수 찾기 성능 실험

주제: 인터넷에서 흥미로운 주제를 하나 찾아서 직접 실험해 봐
결과: 성공 · 행동 10번 · 모델 nvidia/nemotron-3.5-super-vl-120b-a12b

정리

인터넷에서 흥미로운 주제로 리눅스 시스템 성능 벤치마크를 선택하고, 에라토스테네스의 체 알고리즘으로 소수 찾기 속도를 직접 측정했습니다.

작업 내용:
- Ubuntu 시스템 정보(CPU, 메모리) 수집
- Python으로 100만부터 5천만까지 다양한 범위의 소수 개수와 실행 시간 측정
- matplotlib로 실행 시간 그래프를 PNG 파일로 저장
- 결과는 ~/ws/out/benchmark_results.txt와 benchmark_plot.png에 저장

결과 숫자:
- CPU: AMD EPYC 9V74 80-Core Processor, 메모리 약 16GB
- 100만: 78,498개 소수, 0.0071초
- 500만: 348,513개, 0.0365초
- 1천만: 664,579개, 0.0721초
- 2천5백만: 1,565,927개, 0.1977초
- 5천만: 3,001,134개, 0.5049초

알게 된 점:
- 소수 개수는 범위가 커질수록 대략 비례하여 증가하며, 실행 시간도 범위에 비례해 늘어납니다.
- 5천만까지의 소수 찾기도 0.5초 이내로 매우 빠르게 완료되었습니다.
- 인터넷 검색과 위키피디아 접속이 차단되었지만, 터미널과 pip를 활용해 직접 실험을 완료할 수 있었습니다.
