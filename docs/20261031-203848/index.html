인터넷 공개 API로 고양이 상식 수집 및 길이 분포 분석

주제: 인터넷에서 흥미로운 주제를 하나 찾아서 직접 실험해 봐
결과: 성공 · 행동 12번 · 모델 nvidia/nemotron-3.5-super-vl-120b-a12b

정리

인터넷에서 인증이 필요 없는 공개 API를 찾아 catfact.ninja를 선택하고 직접 실험했다. API에서 고양이 상식 50개를 수집하여 평균 길이 160.3자, 최대 387자, 최소 38자, 평균 단어 수 29.1단어로 분석했다. 결과를 ~/ws/out/cat_facts.json에 저장하고, 글자 수 분포 히스토그램을 ~/ws/out/cat_fact_lengths.png로 저장했다. 처음에는 urllib 기본 요청이 403 오류로 실패했으나 User-Agent 헤더를 추가해 해결했고, 초기 스크립트에서 홈 디렉터리 약어 tilde가 경로로 인식되지 않아 os.path.expanduser로 수정해 정상 동작시켰다. 다음에는 여러 공개 API를 비교하거나 수집 데이터를 자연어 처리해 키워드 빈도를 분석해 볼 수 있다.

import json
import urllib.request
import statistics
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt

BASE = "https://catfact.ninja/facts?limit=10&page="
facts = []
for page in range(1, 6):
    url = BASE + str(page)
    try:
        with urllib.request.urlopen(url, timeout=15) as r:
            data = json.loads(r.read().decode("utf-8"))
        for item in data.get("data", []):
            facts.append(item["fact"])
    except Exception as e:
        print("page", page, "error", e)

lengths = [len(f) for f in facts]
words = [len(f.split()) for f in facts]

print("collected facts:", len(facts))
print("avg length:", round(statistics.mean(lengths), 1))
print("max length:", max(lengths))
print("min length:", min(lengths))
print("avg words:", round(statistics.mean(words), 1))

with open("~/ws/out/cat_facts.json", "w", encoding="utf-8") as f:
    json.dump(facts, f, ensure_ascii=False, indent=2)

plt.figure(figsize=(8, 5))
plt.hist(lengths, bins=10, color="#4c72b0", edgecolor="black")
plt.title("Cat Fact Character Length Distribution")
plt.xlabel("Characters per fact")
plt.ylabel("Number of facts")
plt.grid(axis="y", alpha=0.3)
plt.tight_layout()
plt.savefig("~/ws/out/cat_fact_lengths.png", dpi=150)
plt.close()
print("saved graph and json")
