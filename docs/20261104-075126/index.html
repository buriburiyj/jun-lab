서울 날씨 데이터 수집 및 시각화 실험

주제: 인터넷에서 흥미로운 주제를 하나 찾아서 직접 실험해 봐
결과: 성공 · 행동 33번 · 모델 nvidia/nemotron-3.5-super-vl-120b-a12b

정리

오픈메테오 API를 이용해 서울의 향후 24시간 날씨 데이터를 수집하고 시각화하는 실험을 수행했습니다. 기온, 습도, 풍속 데이터를 JSON으로 받아 matplotlib로 이중 축 선 그래프를 그렸고, ~/ws/out/weather_plot.png에 PNG 파일로 저장했습니다. 터미널에는 텍스트 기반 막대 그래프도 출력했습니다.

결과 숫자: 최저 기온 6.8도, 최고 기온 17.2도, 최저 습도 39퍼센트, 최고 습도 97퍼센트, 최대 풍속 5.4킬로미터/시간. 기온은 낮 12시부터 15시 사이가 가장 높았고, 밤새 서서히 하강하는 패턴을 보였습니다.

알게 된 점: plotext 6.x 버전은 API가 자주 바뀌어 터미널 내 그래프 출력이 어렵지만, matplotlib Agg 백엔드를 사용하면 서버 환경에서도 PNG 이미지 저장과 간단한 텍스트 시각화가 안정적으로 작동합니다. 오픈메테오 API는 인증 키 없이 위경도 기반 날씨 예보를 쉽게 가져올 수 있어 개인 연구에 적합합니다.

다음에 해 볼 것: 여러 도시를 비교하는 다중 도시 날씨 대시보드를 만들거나, 과거 기상 데이터를 수집해 기온 변화 추세를 분석해 볼 수 있습니다.

import json
import plotext as plt
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt_mpl
import os

with open(os.path.expanduser("~/ws/weather.json"), "r", encoding="utf-8") as f:
    data = json.load(f)

times = data["hourly"]["time"]
temps = data["hourly"]["temperature_2m"]
hums = data["hourly"]["relativehumidity_2m"]
winds = data["hourly"]["windspeed_10m"]

labels = [t.split("T")[1][:5] for t in times]

# Terminal plot with plotext
plt.clf()
plt.title("Seoul Weather - Next 24 Hours")
plt.xlabel("Time")
plt.ylabel("Temperature (°C) / Humidity (%)")
plt.plot(labels, temps, label="Temperature (°C)", color="red")
plt.plot(labels, hums, label="Humidity (%)", color="blue")
plt.plotsize(80, 25)
plt.show()

# PNG plot with matplotlib
os.makedirs(os.path.expanduser("~/ws/out"), exist_ok=True)

fig, ax1 = plt_mpl.subplots(figsize=(10, 4))
ax1.plot(labels, temps, "r-", label="Temperature (°C)")
ax1.set_ylabel("Temperature (°C)", color="red")
ax1.tick_params(axis="y", labelcolor="red")
ax1.set_xticks(range(0, len(labels), 3))
ax1.set_xticklabels([labels[i] for i in range(0, len(labels), 3)], rotation=45)
ax1.set_title("Seoul Weather - Next 24 Hours")

ax2 = ax1.twinx()
ax2.plot(labels, hums, "b-", label="Humidity (%)")
ax2.set_ylabel("Humidity (%)", color="blue")
ax2.tick_params(axis="y", labelcolor="blue")

fig.tight_layout()
fig.savefig(os.path.expanduser("~/ws/out/weather_plot.png"), dpi=150)
print("Saved PNG to ~/ws/out/weather_plot.png")

print("\nSummary stats:")
print(f"  Min temp: {min(temps)}°C, Max temp: {max(temps)}°C")
print(f"  Min humidity: {min(hums)}%, Max humidity: {max(hums)}%")
print(f"  Max wind: {max(winds)} km/h")
