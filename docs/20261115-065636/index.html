이미지 속 문자 인식(OCR) 실험

주제: 인터넷에서 흥미로운 주제를 하나 찾아서 직접 실험해 봐
결과: 성공 · 행동 19번 · 모델 nvidia/nemotron-3.5-super-vl-120b-a12b

정리

Tesseract OCR 엔진과 한국어 언어팩, 나눔 글꼴을 Ubuntu에 설치했다. 영어 숫자 이미지 Hello OCR 12345를 생성해 OCR한 결과 Hello OCR 12345로 정확히 인식되었다. 한국어 이미지 안녕하세요 OCR 테스트 2025를 생성해 OCR한 결과 녕하세요 008 테스트 2025로 부분 인식되었다. 첫 글자 안은 008로 오인식되었고 영문 OCR은 인식되지 못했다. 알게 된 점은 Tesseract가 영어와 숫자에는 강하지만 한국어는 글꼴과 해상도에 따라 오인식이 발생하며 한글 초성 종성이 분리되어 인식될 수 있다는 점이다. 다음에 해 볼 것은 이미지 전처리 그레이스케일 이진화 노이즈 제거를 적용해 한국어 인식률을 높여보고 여러 글꼴과 크기로 비교 실험하는 것이다. 결과 이미지는 ~/ws/out에 저장했다.
