주제: 목표: 동일한 웹 페이지를 대상으로 파이썬 웹 크롤링 라이브러리들의 다운로드 및 파싱 속도를 비교한다. 할 일: 1. 비교 대상 라이브러리 선정: requests+BeautifulSoup, aiohttp+asyncio+BeautifulSoup, Scrapy, httpx+selectolax, pyppeteer(또는 playwright). 2. 테스트용 URL 선정(예: https://example.com 또는 실제 HTML 구조가 복잡한 공개 페이지). 3. 각 라이브러리별로 10회 반복 요청·HTML 파싱을 수행하고 전체 소요 시간을 측정한다. 4. 평균 응답·파싱 시간과 표준편차를 계산한다. 5. 결과를 표 형태로 정리하고, 비동기/동기 방식, 헤드리스 브라우저 여부 등 부가 정보를 포함한다. 성공 기준: 각 라이브러리별 평균 시간(ms)과 표준편차가 포함된 비교 표를 제공하고, 테스트 환경(파이썬 버전, OS, CPU)도 명시한다.
결과: 미완료 · 행동 39번 · 모델 nvidia/nemotron-3.5-super-vl-120b-a12b

정리

지금까지 한 일

- 테스트 환경 확인: Python 3.12.15, Linux(Azure VM), CPU 4코어. 대상 라이브러리(requests, beautifulsoup4, aiohttp, httpx, selectolax, scrapy, playwright 등) 설치 완료.
- 테스트 URL: https://example.com 사용.
- requests+BeautifulSoup: 10회 반복 측정 완료. 평균 약 69.92 ms, 표준편차 약 8.61 ms.
- aiohttp+asyncio+BeautifulSoup: 10회 반복 측정 완료. 평균 약 33.51 ms, 표준편차 약 12.34 ms.
- httpx+selectolax: 초기에 selectolax modest 백엔드 deprecated 오류가 났으나, lexbor 엔진으로 변경 후 측정 완료. 평균 약 30.10 ms, 표준편차 약 9.75 ms.
- Scrapy: timing_spider.py 작성 및 실행 시도했으나, 측정 결과를 /tmp/scrapy_times.txt에 저장하는 데 실패(종료코드 1, 파일 없음).

    times = []

        t0 = time.perf_counter()
        resp = requests.get(URL, timeout=15)
        soup = BeautifulSoup(resp.text, "html.parser")
        _ = soup.title.string if soup.title else None
        t1 = time.perf_counter()
        times.append((t1 - t0) * 1000.0)
    return times

async def bench_aiohttp_bs4():
    times = []

                text = await resp.text()
            soup = BeautifulSoup(text, "html.parser")
            _ = soup.title.string if soup.title else None
            t1 = time.perf_counter()
            times.append((t1 - t0) * 1000.0)
    return times

def bench_httpx_selectolax():
