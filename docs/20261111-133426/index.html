리눅스 터미널 재미있는 명령어 실험

주제: 인터넷에서 흥미로운 주제를 하나 찾아서 직접 실험해 봐
결과: 성공 · 행동 6번 · 모델 nvidia/nemotron-3.5-super-vl-120b-a12b

정리

인터넷에서 리눅스 터미널 재미있는 명령어를 검색해 cmatrix와 sl을 선택했다. Ubuntu에 두 패키지를 apt로 설치하고 각각 5초씩 실행해 화면 출력을 ~/ws/out/sl.log와 ~/ws/out/cmatrix.log에 저장했다. sl.log는 29KB, cmatrix.log는 108KB로 터미널 제어 코드를 포함한 출력이 정상적으로 저장된 것을 확인했다. 알게 된 점은 cmatrix는 매트릭스 영화 스타일의 녹색 문자 비를, sl은 증기 기관차 ASCII 애니메이션을 보여준다는 점이며, 로그 파일에는 이스케이프 시퀀스가 그대로 기록된다. 다음에는 cowsay나 fortune 같은 다른 터미널 장난 명령어를 추가로 설치해 비교 실험해 볼 수 있다.

결과 파일

  • cmatrix.log
  • sl.log
