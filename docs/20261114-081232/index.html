리눅스 터미널 데이터 시각화 실험

주제: 인터넷에서 흥미로운 주제를 하나 찾아서 직접 실험해 봐
결과: 성공 · 행동 6번 · 모델 nvidia/nemotron-3.5-super-vl-120b-a12b

정리

인터넷에서 termgraph라는 터미널용 CSV 시각화 도구를 찾아서 직접 실험했습니다. pip로 termgraph를 설치하고 월별 매출과 방문자 수를 담은 샘플 CSV 파일을 만들었습니다. 처음에는 헤더가 있는 CSV와 --colors 옵션으로 오류가 났지만, 헤더를 제거하고 --color 옵션을 사용해 성공적으로 막대그래프를 그렸습니다. 결과는 ~/ws/out/termgraph_output.txt에 저장했습니다. 데이터는 1월부터 6월까지로 매출은 120에서 300으로, 방문자는 340에서 900으로 꾸준히 증가하는 추세를 터미널에서 색상 막대로 확인했습니다. 알게 된 점은 termgraph는 헤더 없는 CSV를 요구하며, --color로 여러 열에 색을 지정할 수 있고 터미널에서 바로 그래프를 볼 수 있어 SSH 환경이나 빠른 보고서에 유용하다는 점입니다. 다음에는 matplotlib를 이용해 같은 데이터를 PNG 파일로 저장하고 더 정교한 그래프를 만들어 볼 계획입니다.
