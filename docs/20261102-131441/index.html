인터넷 공개 API로 포켓몬 능력치 분석 실험

주제: 인터넷에서 흥미로운 주제를 하나 찾아서 직접 실험해 봐
결과: 성공 · 행동 14번 · 모델 nvidia/nemotron-3.5-super-vl-120b-a12b

정리

인터넷에서 흥미로운 주제로 공개 API를 이용한 데이터 분석을 선택하고 PokeAPI로 실험했습니다. requests, pandas, matplotlib를 설치하고 10마리 포켓몬(pikachu, charizard, bulbasaur, squirtle, jigglypuff, mewtwo, snorlax, dragonite, gengar, eevee)의 능력치 데이터를 수집했습니다. 수집 결과는 pokemon_stats.csv에 저장했고, 전체 능력치 막대 그래프와 몸무게 대 HP 산점도를 out 폴더에 PNG 파일로 저장했습니다. 분석 결과 mewtwo가 전체 능력치 합계로 가장 높았고, snorlax가 몸무게가 가장 무겁고 HP도 높았습니다. 인터넷 공개 API를 직접 호출해 데이터를 가져와 분석하고 시각화까지 완료한 점이 주요 성과입니다. 다음에는 더 많은 포켓몬 데이터를 수집하거나 세대별 능력치 비교, 타입별 분석을 추가해 볼 수 있습니다.

import requests
import pandas as pd
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt

pokemon_names = [
    'pikachu', 'charizard', 'bulbasaur', 'squirtle', 'jigglypuff',
    'mewtwo', 'snorlax', 'dragonite', 'gengar', 'eevee'
]

data = []
for name in pokemon_names:
    url = f'https://pokeapi.co/api/v2/pokemon/{name}'
    resp = requests.get(url, timeout=10)
    if resp.status_code == 200:
        j = resp.json()
        stats = {s['stat']['name']: s['base_stat'] for s in j['stats']}
        data.append({
            'name': j['name'],
            'height': j['height'],
            'weight': j['weight'],
            'base_experience': j['base_experience'],
            'hp': stats.get('hp', 0),
            'attack': stats.get('attack', 0),
            'defense': stats.get('defense', 0),
            'special-attack': stats.get('special-attack', 0),
            'special-defense': stats.get('special-defense', 0),
            'speed': stats.get('speed', 0),
        })
    else:
        print(f'failed: {name} status {resp.status_code}')

df = pd.DataFrame(data)
df.to_csv('pokemon_stats.csv', index=False)
print(df)

total_stats = df[['hp','attack','defense','special-attack','special-defense','speed']].sum(axis=1)
df['total'] = total_stats

plt.figure(figsize=(10,6))
plt.bar(df['name'], df['total'], color='skyblue')
plt.title('Total Base Stats by Pokemon')
plt.xlabel('Pokemon')
plt.ylabel('Total Base Stat')
plt.xticks(rotation=45)
plt.tight_layout()
plt.savefig('out/pokemon_total_stats.png')
print('saved out/pokemon_total_stats.png')

plt.figure(figsize=(10,6))
plt.scatter(df['weight'], df['hp'], s=100, alpha=0.7)
for i, row in df.iterrows():
    plt.annotate(row['name'], (row['weight'], row['hp']), fontsize=8)
plt.title('Weight vs HP')
plt.xlabel('Weight (hg)')
plt.ylabel('HP')
plt.tight_layout()
plt.savefig('out/pokemon_weight_hp.png')
print('saved out/pokemon_weight_hp.png')

print('done')
