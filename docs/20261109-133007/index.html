인터넷 흥미 주제 실험: 수열과 랜덤워크 시각화

주제: 인터넷에서 흥미로운 주제를 하나 찾아서 직접 실험해 봐
결과: 성공 · 행동 19번 · 모델 nvidia/nemotron-3.5-super-vl-120b-a12b

정리

지금까지 한 일:
- 인터넷에서 찾은 흥미로운 주제(피보나치 수열, 소수 간격, 랜덤 워크 등)로 실험 코드(`experiment.py`)를 작성함.
- 처음에는 터미널에 그래프를 그리는 `plotext`를 사용하려 했으나 `clf`, `clear`, `title` 등이 없어 반복 오류가 발생함.
- `plotext` 문서와 사용 가능한 함수 목록을 확인한 뒤, `matplotlib`로 방향을 바꿈.
- `pip install matplotlib`로 라이브러리를 설치하고 `python3 ~/ws/experiment.py`를 실행함.
- 종료 코드 0으로 성공하며, `~/ws/out/`에 `fibonacci.png`, `prime_gaps.png`, `random_walk.png` 3개의 PNG 파일을 저장함.

막힌 점:
- 현재 막힌 점은 없음. `plotext` API 오류는 `matplotlib`로 교체해 해결됨.

  • fibonacci.png
  • prime_gaps.png
  • random_walk.png

import plotext as plt
import math
import random

# 1. 피보나치 수열 단말기 그래프
fib = [0, 1]
for i in range(2, 30):
    fib.append(fib[-1] + fib[-2])
plt.clf()
plt.title("Fibonacci Sequence (Terminal)")
plt.plot(fib, marker="dot")
plt.show()

# 2. 소수 간격 단말기 그래프
def is_prime(n):
    if n < 2:
        return False
    for i in range(2, int(math.sqrt(n)) + 1):
        if n % i == 0:
            return False
    return True

primes = [n for n in range(2, 200) if is_prime(n)]
gaps = [primes[i+1] - primes[i] for i in range(len(primes)-1)]
plt.clf()
plt.title("Prime Gaps (Terminal)")
plt.plot(gaps, marker="x")
plt.show()

# 3. 랜덤 워크 단말기 그래프
random.seed(42)
walk = [0]
for _ in range(100):
    walk.append(walk[-1] + random.choice([-1, 1]))
plt.clf()
plt.title("1D Random Walk (Terminal)")
plt.plot(walk, color="blue")
plt.show()

print("단말기 그래프 출력 완료")

# 2. 소수 간격
def is_prime(n):
    if n < 2:
        return False
    for i in range(2, int(math.sqrt(n)) + 1):
        if n % i == 0:
            return False
    return True

gaps = [primes[i+1] - primes[i] for i in range(len(primes)-1)]

plt.figure(figsize=(8,4))
