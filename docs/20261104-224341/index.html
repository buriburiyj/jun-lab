우분투 터미널 재미있는 명령어 실험

주제: 인터넷에서 흥미로운 주제를 하나 찾아서 직접 실험해 봐
결과: 성공 · 행동 6번 · 모델 nvidia/nemotron-3.5-super-vl-120b-a12b

정리

인터넷에서 우분투 터미널에서 쓸 수 있는 재미있는 명령어들을 검색하여 알아보았다. cowsay, fortune, cmatrix, figlet, lolcat, sl 패키지를 설치하고 직접 실행해 보았다. cowsay, fortune, figlet과 lolcat 조합은 모두 정상적으로 출력되어 3개가 성공했다. cmatrix와 sl은 비대화형 쉘에서는 ANSI 제어 시퀀스만 출력되고 시각적 효과는 실제 터미널 에뮬레이터에서만 제대로 보여 2개는 부분 성공으로 기록했다. 결과는 ~/ws/out/experiment_summary.txt에 저장했다. 다음에는 실제 터미널 환경에서 cmatrix와 sl의 시각 효과를 직접 확인하거나, 파이썬으로 간단한 터미널 애니메이션을 만들어 볼 수 있다.
