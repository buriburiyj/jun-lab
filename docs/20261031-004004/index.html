파이썬 웹 크롤링 라이브러리 속도 비교 연구

주제: 파이썬 웹 크롤링 라이브러리(예: requests+BeautifulSoup, aiohttp+asyncio, httpx, scrapy 등)를 3~4개 선정하고, 동일한 웹 페이지를 대상으로 각 라이브러리로 HTML을 가져오는 속도를 측정한다. 목표: 각 라이브러리의 평균 응답 시간(5회 반복)과 성공률을 비교 표로 정리. 할 일: 1) 라이브러리 설치 및 기본 크롤링 코드 작성, 2) 동일 URL에 대해 5회 요청 실행, 3) 평균 시간 및 오류율 계산, 4) 결과를 표와 간단한 분석으로 정리. 성공 기준: 모든 라이브러리의 평균 응답 시간과 성공률이 포함된 표와, 어느 라이브러리가 가장 빠른지에 대한 결론이 제공될 때.
결과: 성공 · 행동 6번 · 모델 nvidia/nemotron-3.5-super-vl-120b-a12b

정리

요청과 BeautifulSoup 파싱, aiohttp와 asyncio, httpx, scrapy 네 가지 라이브러리로 동일한 URL(https://httpbin.org/get)에 대해 각각 5회 반복 요청을 수행하고 평균 응답 시간과 성공률을 측정했습니다. requests와 BeautifulSoup은 평균 0.1187초에 5회 모두 성공(100퍼센트), aiohttp와 asyncio는 평균 0.0554초에 5회 모두 성공(100퍼센트), httpx는 평균 0.1385초에 5회 모두 성공(100퍼센트), scrapy는 평균 0.2691초에 1회만 성공(20퍼센트)했습니다. 결과는 ~/ws/out/benchmark_results.csv에 저장되었습니다. 알게 된 점은 단일 페이지 반복 요청에서는 비동기 클라이언트인 aiohttp가 가장 빠르고, scrapy는 전체 프레임워크 특성상 단일 요청 오버헤드가 커서 이 측정 환경에서는 적합하지 않다는 점입니다. 다음에는 더 많은 반복 횟수와 동시 요청 환경, 실제 뉴스 사이트나 쇼핑몰 등 다양한 도메인에서 측정해 보고, 메모리 사용량과 파싱 시간까지 포함해 비교해 볼 계획입니다.

import time
import csv
import asyncio
import statistics

import requests
from bs4 import BeautifulSoup
import aiohttp
import httpx
from scrapy.crawler import CrawlerProcess
from scrapy.spiders import Spider
from scrapy.utils.project import get_project_settings

URL = "https://httpbin.org/get"
N_REPEAT = 5
RESULTS = []


def bench_requests():
    times = []
    success = 0
    for i in range(N_REPEAT):
        try:
            t0 = time.perf_counter()
            r = requests.get(URL, timeout=10)
            dt = time.perf_counter() - t0
            if r.status_code == 200:
                BeautifulSoup(r.text, "html.parser")
                success += 1
            times.append(dt)
        except Exception as e:
            times.append(None)
            print(f"  requests 실패 {i+1}: {e}")
    return times, success


async def bench_aiohttp():
    times = []
    success = 0
    async with aiohttp.ClientSession() as session:
        for i in range(N_REPEAT):
            try:
                t0 = time.perf_counter()
                async with session.get(URL, timeout=10) as r:
                    text = await r.text()
                    dt = time.perf_counter() - t0
                    if r.status == 200:
                        BeautifulSoup(text, "html.parser")
                        success += 1
                    times.append(dt)
            except Exception as e:
                times.append(None)
                print(f"  aiohttp 실패 {i+1}: {e}")
    return times, success


def bench_httpx():
    times = []
    success = 0
